HUCViewS

心臓・大動脈 3D ビューア（3D Slicer ＋ AI）

研究・教育用です。医療機器ではありません。診断・治療方針の決定には使わず、必ず元の画像で確認してください。患者データはお使いの PC の中だけで扱われ、外へ送られることはありません。

Windows 10 / 11

ダウンロード（Windows）
  1. ダウンロードした HUCViewS_Windows.exe を開く
  2. 青い画面「Windows によって PC が保護されました」が出たら、「詳細情報」→「実行」
  3. インストール画面が終わるまで待つ（10〜30 分）→「HUCViewS を起動」

管理者権限は不要。デスクトップとスタートメニューに「HUCViewS」ができます。削除は「設定 → アプリ」から。

Mac

ダウンロード（Mac）
  1. ダウンロードした HUCViewS Installer をダブルクリック
  2. 「開けません」と出たら：システム設定 → プライバシーとセキュリティ の下の方にある「このまま開く」を押す
  3. ターミナルが開いてインストールが進む（10〜30 分）。終わると「アプリケーション」に HUCViewS ができます
うまくいかないとき（ターミナルに貼る方法） curl -fsSL https://github.com/lfb15345-del/HUCViewS/releases/latest/download/install_mac.sh | bash

Mac では AI の自動認識が遅い、または動かないことがあります。その場合は Windows で作った症例を開いて見てください。

使い方（3 ステップ）

  1. HUCViewS を起動し、CD-R を入れて「CD-R から読み込む」（または「フォルダから…」）
  2. ★の付いたシリーズのまま「3D を作る」（初回 5〜10 分）
  3. 「見たいもの」で 心臓 / 大動脈 / 血管すべて / 骨と血管 を切り替え、マウスで回す・切る・測る

心腔の左右の色分けには、TotalSegmentator の無料学術ライセンスが必要です（申請はこちら）。起動後の「AI ライセンスを登録する」に番号を入れてください。新しい版は起動のたびに自動で入ります。
